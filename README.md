# Vendly - ERP para Pequenos Estabelecimentos

Sistema de gestão integrado (ERP) desenvolvido para otimizar o controle operacional de pequenos comércios e estabelecimentos, facilitando a administração de produtos, estoque, fornecedores e funcionários.

## 🚀 Tecnologias Utilizadas
* **HTML5 / CSS3 / JavaScript (ES6+ Modules)**
* **Bootstrap 5** (Estilização e componentes responsivos)
* **jQuery & DataTables** (Manipulação e exibição avançada de dados em tabelas)
* **Web Components** (Arquitetura modular para componentes reutilizáveis)

## 📁 Estrutura do Projeto
vendly/
├── public/
│   ├── assets/
│   └── data/           # Mock data em formato JSON
├── src/
│   ├── apiServices/    # Serviços para consumo de dados
│   ├── components/     # Web Components (Navbar, Sidebar, Shell, Table, etc.)
│   ├── pages/          # Páginas e views da aplicação
│   └── app.js          # Ponto central de importação e injeção de dependências
├── index.html
└── package.json
